Quick start

Three Python files. Set env vars, run python scheduler.py to start all agents.

agent1_lead_scraper.py — runs daily at 8am

# Run daily via scheduler.py
# Fetches 270 leads/day from SiteScout
# Deduplicates against seen_leads.json
# Calls Claude API to write personalised email
# Pushes lead + email to Instantly.ai campaign

python agent1_lead_scraper.py   # run once manually
agent2_reply_handler.py — runs every 30 min

# Polls Instantly.ai for new replies
# Classifies each reply: INTERESTED / NOT_INTERESTED / QUESTION etc
# For INTERESTED: generates demo URL, sends reply with mockup + Calendly link
# For QUESTION: Claude writes an answer
# Calendly webhook → Google Calendar event auto-created

python agent2_reply_handler.py  # run once manually
agent3_website_builder.py — triggered after close

# Call build_and_deliver() after you close a deal
from agent3_website_builder import build_and_deliver

build_and_deliver(
    customer_email="owner@joesplumbing.com",
    customer_name="Joe",
    business_name="Joe's Plumbing",
    industry="plumbing",
    location="Miami, FL",
    notes="Family-owned, emergency services"
)

Import this JSON into n8n. Go to n8n → Workflows → Import from JSON and paste.


{
  "name": "WebCraft AI Agent System",
  "nodes": [
    { "Daily trigger 8am" → SiteScout leads → Deduplicate → Claude email → Instantly },
    { "Every 30min" → Fetch replies → Claude classify → If INTERESTED → Demo email → Reply },
    { "Calendly webhook" → Extract booking → Google Calendar event }
  ]
}

Download the full n8n_workflow.json file from the files panel above.


# 1. Install dependencies
pip install -r requirements.txt

# 2. Set environment variables (or paste into Setup tab above)
export ANTHROPIC_API_KEY="sk-ant-..."
export INSTANTLY_API_KEY="your-key"
export INSTANTLY_CAMPAIGN_ID="camp_..."
export SITESCOUT_API_KEY="your-key"
export DURABLE_API_KEY="your-key"
export CALENDLY_LINK="https://calendly.com/you/30min"
export YOUR_EMAIL="you@domain.com"
export YOUR_NAME="Alex"

# 3. Authenticate Google Calendar (one-time)
python agent2_reply_handler.py  # browser opens for OAuth

# 4. Start the scheduler (keeps running 24/7)
python scheduler.py

# 5. For Calendly webhooks — expose with ngrok or deploy to a server
ngrok http 5000
# Then set webhook URL in Calendly: https://your-ngrok-url/calendly-webhook
